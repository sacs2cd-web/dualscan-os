# VisaUSD FiveM resources

Free downloadable resources and browser demonstrations: https://dualscan.cloud/gtavi/

## VisaUSD Radio 1.0.0

`visausd-radio/` contains the complete public FiveM resource source and its 51 OGG songs. Preserve its folder name when installing it in a FiveM server. Follow the resource README and included license/asset notices.

The hosted player at https://dualscan.cloud/gtaradio/ uses the OGG files from this public repository folder through GitHub raw URLs. The browser player shuffles separately for each listener; the FiveM resource owns a shared server broadcast. The player site does not need to duplicate the audio inside the GitHub Pages docs tree.

The source audio files remain byte-identical to the verified release. Songs and artwork retain their existing rights, separate from the software MIT license. No private workstation source files or account data are included.
