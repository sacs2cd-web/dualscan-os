SERVER OWNERS / START HERE

Unzip.
Enable.
Connect.

Install these resources on your FiveM server. Players receive the required client assets when they join.

  1. 01

    Keep the resource folders intact.

    Extract the ZIP into your server’s resources directory. Keep the exact folder names.

    resources/
  visausd-fivem-phone/
    fxmanifest.lua
  visausd-radio/
    fxmanifest.lua
  2. 02

    Add the resources you want.

    Add these lines to your existing server.cfg, then start or restart the resources.

    ensure visausd-fivem-phone
ensure visausd-radio
  3. 03

    Open the phone. Tune the station.

    Use F6 or /visausd for the phone. Set your four-digit PIN. For Radio, enter a vehicle and choose the Worldwide FM slot, now named VisaUSD Radio.

    The radio wheel icon remains Worldwide FM unless you install the build-specific atlas patch described in the ZIP. Game developers connect credit entries through the phone’s included server API.

A few things to know.

Do players install the ZIP?

The server owner installs it. FiveM delivers the necessary phone UI, scripts and radio audio to connected players.

Does the phone include a cryptocurrency wallet?

No. This device contains only the server’s non-redeemable Gaming Credits system. There are no blockchain SDKs, crypto wallet keys, recovery phrases or cryptocurrency transactions.

Can I use the resources independently?

Yes. The phone and radio are separate standalone resources. Neither requires ESX or QBCore. The phone requires a current FXServer artifact with its Node 22 runtime.

Is this compatible with GTA VI?

This release targets FiveM for GTA V PC. No GTA VI compatibility is claimed. The radio scheduler is separated from its platform adapters for future work.
