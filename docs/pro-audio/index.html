THE RECORDING LISTENER / 03

Diamond Certified
Recording.

A recording standard enforced at the input. The Diamond designation appears only while the recording meets the acceptance criteria.

Diamond Certified
Recording

Qualify. Record. Verify.

SAMPLE PEAK≤ −0.01 dBFS
TRUE PEAK≤ −0.01 dBTP
AVAILABLE M / S / I LOUDNESS≤ −5.8 LUFS

Diamond Certified Recording is Dualscan’s own recording-acceptance designation.

  1. 01

    Listen before you record

    Monitor the ADC input and adjust levels at the source. Four consecutive seconds of qualifying input enable recording and reveal the Diamond logo with the “Diamond Certified Recording” label above the meters.

  2. 02

    Stay within every ceiling

    Sample peak and true peak must stay at or below −0.01 dB. Every available momentary, short-term and integrated loudness measurement must stay at or below −5.8 LUFS.

  3. 03

    Any breach stops the take

    Exceed a ceiling and recording stops, certification is withdrawn, and the entire take is rejected. No accepted .diamond file is published. Input monitoring continues.

  4. 04

    Correct, requalify, then record

    Set the source level and qualify the input again for a new take. A completed recording receives final peak and loudness checks before it enters the Diamond library.
