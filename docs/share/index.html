THE WORKFLOW / 01

A project you can
move and verify.

Share works with the actual files. It streams binary content, preserves nested paths, resolves Git LFS payloads and checks file identities before reporting completion.

01

Connect and inspect

Choose a USB folder or pin a public GitHub commit. Find nested Smart Switch snapshots without hardcoding a drive, device ID or backup timestamp.

Standalone APKs are identified by their Android package and detected build. Encrypted Smart Switch presence is reported independently, with its internal version unverified.

02

Back up to your destination

Save a selected USB dataset to your own GitHub, GitLab.com or Bitbucket Cloud repository, or publish a verified Dualscan dataset in a new random folder in your AWS S3 bucket.

Review the destination first. AWS dataset files are public after anonymous verification; protect personal additions with SSS encryption before upload. Existing files and snapshots are not replaced.

03

Restore and read back

Import a filename.dualscan project, connect its Git or AWS source, and select the destination USB folder. Source identities and path collisions are checked before writing.

A verified package wrapper is removed so SmartSwitchBackup2, OEM installers and the original files are placed directly in the USB root. Size, hash and destination read-back checks gate verified completion.

THE ORIGINAL STAYS ORIGINAL / 02

Add your snapshots.
Keep the foundation.

A Dualscan SSS derivative must preserve every original file and app from its pinned official reference. The suite checks the complete original file identities before accepting a derivative.

The official SSS image is listed first in the project. User-added snapshots remain separate beneath SmartSwitchBackup2, with both required snapshot markers checked. Changing or removing an original file blocks the derivative workflow.

THE PORTABLE PROJECT / 03

One .dualscan file.
Pick up where you need it.

A versioned project file carries the pinned source, file paths, sizes, integrity identities and original-image protection reference. Its Typelocker source locator travels with it.

The project format is data only. It contains source metadata rather than the backup’s binary payloads, and exports exclude account credentials. Binary Typelocker app protection prevents plain-text manifest viewing. Add a passphrase for confidential metadata: the shared app key is recoverable from the app. The source must remain reachable for restore.

Chrome installation guide ↗

Install the desktop app

First compare your download’s SHA-256 with SHA256SUMS.txt. A match checks download integrity; it does not establish publisher identity or malware safety.

macOS · ad-hoc signed, not notarized
  1. Download the ZIP for your Mac: Apple silicon (ARM64) or Intel (x64), then verify its SHA-256.
  2. Unzip it and move Dualscan™ Share Suite into Applications. Try opening the app.
  3. If macOS cannot verify the developer or notarization, proceed only if you trust this exact download. Open System Settings → Privacy & Security → Open Anyway, then confirm Open and authenticate if requested. This creates an exception for this app.
  4. If macOS reports malware, damage, or a policy block, stop and contact support or your administrator.

See Apple’s app-opening guidance.

Check the Mac download’s SHA-256
shasum -a 256 ~/Downloads/Dualscan-Share-1.3.2-mac-arm64.zip

For Intel, use Dualscan-Share-1.3.2-mac-x64.zip instead. Compare the entire digest with the matching filename in SHA256SUMS.txt.

Windows · unsigned portable EXE
  1. Download the Windows x64 EXE and verify its SHA-256. Open it as your normal user; no installer is required.
  2. If SmartScreen identifies an unrecognized app, choose More info → Run anyway only after verifying this download and deciding you trust it.
  3. If that option is unavailable, or Smart App Control or an organization policy blocks the app, stop and contact support or your administrator. Keep those protections enabled.

See Microsoft’s SmartScreen guidance and direct-distribution guidance.

Check the Windows download’s SHA-256
Get-FileHash "$env:USERPROFILE\Downloads\Dualscan-Share-1.3.2-win-x64.exe" -Algorithm SHA256

Run this in PowerShell. Compare the entire digest with the matching filename in SHA256SUMS.txt.

BEFORE YOU BEGIN

Your storage.
Your destination.

  • Use a USB 3 capable drive and port for better throughput. Thousands of small files and full verification add work beyond a sequential speed rating.
  • Confirm the selected folder is the intended USB root and has enough free space. The browser cannot certify the connector, drive identity or free capacity.
  • AWS uploads require scoped credentials and a public-read policy for the reviewed random dataset folder. Downloads of public projects need no AWS keys. Chrome needs the regional host grant and bucket CORS. AWS storage and request charges apply.
  • Tokens and AWS credentials stay in session memory. Project files and evidence reports exclude them. There is no publisher-operated transfer relay.
  • A verified file transfer does not establish a successful Samsung Smart Switch restore. Device and backup compatibility still apply.
